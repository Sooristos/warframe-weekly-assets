# warframe-weekly-assets

Bibliothèque d’images organisée pour le projet Warframe Weekly.

## Dossiers

- `circuit-normal` : images du Circuit normal
- `circuit-sp` : images du Circuit Steel Path
- `pnj` : images des PNJ
- `archontes` : images liées aux Archontes
- `teshin` : images liées à Teshin
- `calendrier-1999` : images du calendrier 1999

## Convention de nommage

- minuscules
- tirets pour séparer les mots
- noms explicites

Exemples :
- `semaine-01.png`
- `archonte-boreal.png`
- `teshin-offre-01.png`
- `janvier-1999.png`
