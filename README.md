# warframe-weekly-assets

Bibliothèque d’images organisée pour le projet Warframe Weekly.

## Dossiers

- `circuit-normal` : images des warframes du Circuit normal
- `circuit-sp` : images des armes Circuit Steel Path
- `pnj` : images des PNJ
- `archontes` : images liées aux Archontes
- `teshin` : images liées aux récompenses hebdos Teshin
- `calendrier-1999` : images récompenses hebdos du calendrier 1999
- `missions` : icones des missions

## Convention de nommage

- minuscules
- tirets pour séparer les mots
- noms explicites

Exemples :
- `circuit_normal_semaine_1`
- `incarnon_semaine_1`
- `archonte_rouge`
- `riven_fusil_pompe`
